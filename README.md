# Preppy

Daily exam-simulation platform for IBPS Specialist Officer (IT) aspirants.
See [PRD.md](PRD.md) for the full specification.

**Status:** paper-ingestion pipeline only. No web app yet.

## What exists

| Path | Purpose |
|---|---|
| `lib/types.ts` | Shared shapes and the PRD §3.1 pattern constants |
| `lib/parser.ts` | Line-based grammar parser for the PDF contract (PRD §7) |
| `lib/validate.ts` | Blocking errors vs warnings (PRD §6.9.1) |
| `lib/extract.ts` | PDF text-layer extraction with line reconstruction |
| `scripts/parse.ts` | CLI paper checker |
| `scripts/make-samples.ts` | Renders the `.txt` sources to PDF |
| `scripts/roundtrip.ts` | Proves a paper survives PDF extraction unchanged |
| `docs/sample.txt` / `.pdf` | A complete 55-question paper with a DI set, a seating puzzle and an RC passage |
| `docs/template.txt` / `.pdf` | Empty skeleton to fill in |
| `docs/cheatsheet.md` | One-page format reference for the admin |

## Usage

```bash
npm install

npm run parse -- docs/sample.pdf        # check a paper
npm run parse -- paper.pdf --images ./img
npm run parse -- paper.pdf --json       # machine-readable

npm run make-samples                    # regenerate sample.pdf / template.pdf
npx tsx scripts/roundtrip.ts docs/sample.txt docs/sample.pdf
npm test
```

Exit codes: `0` publishable, `1` blocking errors, `2` bad usage.

## Known limit

`docs/sample.pdf` is generated by a library, so it extracts more cleanly than a
Word or Google Docs export. The pipeline is proven end to end against it, but
**the format is not proven against a real export until one is run through
`npm run parse`.** That is the next thing to do.
