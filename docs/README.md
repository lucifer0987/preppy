# Documents

Everything written about Preppy lives here.

| File | What it is | How to read it |
|---|---|---|
| **[architecture.html](architecture.html)** | The main reference. How the system is built, in eight diagrams, then local and production setup step by step. Written for someone who does not write web code | Open in a browser |
| **[prd.html](prd.html)** | Product requirements. What was decided, what shipped, and what changed during the build | Open in a browser |
| **[setup.md](setup.md)** | The setup commands as a bare checklist, for when you already know what they do | Terminal or GitHub |

The two HTML files are self-contained: no network needed, nothing to install.
Double-click, or `open architecture.html`.
